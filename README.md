# metaDATAinh

Локальный веб-редактор метаданных на **Python + Flask + ExifTool** для macOS. Работает в браузере, а файлы обрабатываются на вашем компьютере.

## Возможности

- Выбор файла через стандартный диалог macOS или drag-and-drop.
- Просмотр всех метаданных, которые ExifTool смог извлечь: EXIF, XMP, IPTC, QuickTime, PDF, аудиотеги и другие группы.
- Поиск по названиям групп, тегам и значениям, фильтр редактируемых полей.
- Редактирование существующих записываемых тегов, очистка выбранных тегов и добавление новых.
- Сохранение выбранных тегов как именованного шаблона в локальном JSON-файле.
- Применение шаблона к другому файлу без массового удаления остальных тегов.
- Сброс правок, скачивание результата с суффиксом \`_edited\`.
- Исходный файл никогда не перезаписывается; ошибка ExifTool не заменяет рабочую копию.

**Важно:** «показать все» означает все теги, *распознанные ExifTool*. Не все метаданные физически доступны для записи. Принадлежность тега к списку записываемых не гарантирует, что конкретный файловый формат поддерживает изменение. ExifTool проверяет это при сохранении.

## Установка на macOS

Понадобятся **Python 3.10+**, Homebrew и ExifTool.

\`\`\`bash
brew install exiftool
git clone https://github.com/tranzistrina/metaDATAinh.git
cd metaDATAinh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
\`\`\`

Откройте в браузере **http://127.0.0.1:5000**.

**Альтернативный запуск:** из папки проекта выполните \`zsh run_mac.command\`. Скрипт создаёт виртуальное окружение, устанавливает Python-зависимости и открывает браузер. Для запуска двойным кликом в Finder сначала разрешите исполнение командой \`chmod +x run_mac.command\`.

## Как пользоваться

1. Перетащите файл в область загрузки или нажмите «выберите на Mac».
2. Просмотрите метаданные. Редактируемые значения имеют текстовое поле; остальные показаны только для чтения.
3. Измените значения, при необходимости добавьте тег вида \`XMP-dc:Title\` или выберите «Очистить тег».
4. Нажмите «Сохранить в копию». Скачайте файл кнопкой «Скачать копию».
5. Чтобы создать шаблон, отметьте галочками нужные редактируемые поля (или добавьте новые), укажите имя и нажмите «Сохранить как шаблон».
6. Для нового файла выберите сохранённый шаблон и нажмите «Применить шаблон».

Примеры тегов, которые могут поддерживаться в зависимости от файла:

| Тег | Значение |
| --- | --- |
| \`XMP-dc:Title\` | Название |
| \`XMP-dc:Description\` | Описание |
| \`EXIF:Artist\` | Автор |
| \`EXIF:Copyright\` | Правообладатель |
| \`IPTC:Keywords\` | Ключевые слова |

Для **тегов-массивов** редактируйте значение как JSON-массив строк, например \`["portrait", "studio"]\`. При применении шаблона значения соответствующих тегов заменяются, а остальные сохраняются насколько позволяет формат.

## Как хранятся данные

\`\`\`text
metaDATAinh/
├── app.py                    # Flask API, ExifTool, безопасность, шаблоны
├── templates/index.html      # Интерфейс
├── static/app.css
├── static/app.js
├── tests/test_app.py
├── requirements.txt
├── requirements-dev.txt
├── run_mac.command
└── instance/                 # Создаётся локально, игнорируется Git
    ├── templates.json        # Ваши сохранённые шаблоны
    └── uploads/<uuid>/       # Исходная и рабочая копии
\`\`\`

Загруженные файлы находятся только в локальном каталоге \`instance/uploads/\`; старые каталоги загрузок (старше 24 часов) удаляются **при следующем запуске** приложения. Шаблоны не удаляются автоматически. При необходимости можно вручную очистить \`instance/uploads/\`.

Сервер слушает только \`127.0.0.1\`, а не внешнюю сеть; для меняющих запросов используется CSRF-токен. Размер файла ограничен **100 МиБ**. Не разворачивайте этот локальный инструмент как публичный веб-сервис без отдельной аутентификации, контроля нагрузки и политики хранения.

### Конфигурация

- \`PORT\`: HTTP-порт (по умолчанию \`5000\`).
- \`METADATA_DATA_DIR\`: альтернативная директория локальных данных.
- \`EXIFTOOL_PATH\`: полный путь к бинарному файлу ExifTool.
- \`METADATA_SECRET\`: постоянный секрет Flask-сессии (необязателен для обычного локального запуска).

### Тесты

\`\`\`bash
python -m pip install -r requirements-dev.txt
pytest -q
\`\`\`

Тесты подменяют ExifTool, поэтому проверяют работу Flask API, защиту, шаблоны и атомарность записи без настоящего исполняемого файла. Перед использованием на важных документах рекомендуем проверить работу и в реальном ExifTool на копиях файлов.

## Ограничения

- Служебные сведения, например имя файла, права доступа и даты файловой системы, намеренно закрыты от записи через редактор.
- Некоторые контейнеры (особенно RAW, видео, PDF) разрешают запись не всех тегов, которые можно прочитать. Ограничения задаёт ExifTool и формат.
- Для бинарных данных, структурированных объектов и нестандартных maker notes интерфейс показывает считанное значение, но может не позволять редактирование.
- Это локальный Flask-инструмент, **не подписанное приложение \`.app\`**. Нужны Python и ExifTool.
